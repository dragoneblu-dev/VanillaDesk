#architettura #release-2026 ↪ Specifiche Tecniche

VanillaDesk è un ambiente di lavoro ibrido progettato per garantire prestazioni estreme a latenza zero, combinando la flessibilità di un elaboratore di testi alla precisione di un database relazionale in-memory.

Architettura del Motore Locale

I dati risiedono fisicamente sul disco rigido locale del computer. Il sistema adotta crittografia AES-GCM a 256-bit nativa per la massima riservatezza.

function calcolaGiorniRimanenti(dataScadenza) {
    const oggi = new Date();
    const scadenza = new Date(dataScadenza);
    return Math.ceil((scadenza - oggi) / (1000 * 60 * 60 * 24));
}
